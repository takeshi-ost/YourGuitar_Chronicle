Authentication — GPT連携

実験用キュー（Claimは変更しません）

Mac内のYGCへ接続する複数申請の実験キューです。GoogleやAI APIキーは不要です。画像を準備後、デスクトップ側にMCPを接続して審議します。ChatGPTが画像を取得すると画像がChatGPTへ送られます。申請・画像・診断結果を実験専用の保存先に保持します。Claim・所有権には反映しません。

追加した申請は上書きされません。同じIDでもrevisionごとに記録します。接続キーと申請は再起動後も保持し、キーは明示的に失効するまで有効です。審議中は2時間確保し、時間切れは3回でエラーとして停止します。保存上限は100件・画像合計256MBです。

申請ID / revision状態・採否受付 / 開始 / 完了 (UTC)試行・操作

各定期実行の開始時点にある未審査申請を、全件順番に処理する指示です。途中で追加された申請は次回に回します。MCPツールとスケジュールの指示文を更新してください。接続診断は申請を確保せず、審議を開始しません。

デスクトップ側のMCP接続設定

CodexのMCP設定へ以下を追加し、PASTE_TOKENを上の接続キーに置き換えてください。既存設定は上書きせず、このサーバー項目だけ追加します。設定ファイルにキーを保存するため、ご自身のMacだけで使用してください。接続設定後に新しいチャットを開きます。ChatGPTデスクトップで同じ設定方式が使えるかは提供機能によります。
