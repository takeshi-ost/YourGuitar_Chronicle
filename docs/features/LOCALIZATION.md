# 言語切替の機能仕様

対象：現在のUI多言語化。既定は英語、日本語辞書を提供する。ヘッダーの言語選択はブラウザ単位で保持し、切替後に再読込する。アカウントのProfile項目ではない。

画面ラベルと既知APIエラーを辞書参照する。ユーザー入力、保存済み診断文章、ID・URL・機械用の状態値は原文を保持する。英語辞書を基準に、日本語辞書を人が直接修正できる。既存の修正文言を自動翻訳で上書きしない。

辞書は `app/src/ygc/static/locales/en.json` と `ja.json`、言語一覧は `manifest.json`。ブラウザ側は `i18n.js`、サーバー側は `localization.py` を使う。言語を追加するときは同じキーを持つ辞書とmanifestの項目を追加し、欠落キー・レイアウトを確認する。

ユーザー操作は[ユーザーガイド](../user-guide/README.md)、共通画面実装は[UI構造](../development/UI_STRUCTURE.md)を参照。
