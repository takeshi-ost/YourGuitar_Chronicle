# Your Guitar Chronicle — 企画概要

Your Guitar Chronicle (YGC) はギターという**物理的な一個体**の履歴を、販売情報や所有・修理・演奏などの記録から編むサービスである。所有権を法的に保証する台帳ではなく、出典と判断状態を添えて後からたどれるChronicleを作る。

- `Individual` は一個体の継続した識別子。メーカー・モデル・シリアルの一致は照合材料であり、単独で真偽を保証しない。
- `Claim` は掲載、所有、仕様、出来事などの主張。現時点で有効なClaimを時系列に評価して現在の表示値を作る。
- `Observation` は外部で見た掲載の出典・取得日時など。意味情報の直接の更新元ではない。
- ユーザーは自分のギターの来歴を残し、第三者の主張を承認・否定できる。信頼が争われる情報は削除して上書きするのではなく、判定と履歴を保持する。
- 公開Top Pageから個体とClaimを閲覧できる。ユーザー同士の参加は、関連するギターを発見したときに自然に始められる設計を目指す。

現在はローカル試作。Reverb APIの収集と利用者の入力を検証している。対象はヴィンテージに限定しない。現在の自動収集は**メーカーと有効なシリアル番号を判別できる個体**に絞るが、利用者の手動登録は別の入口として扱う。外部Listing IDの一致と物理的な個体の一致は別々に判定する。

将来は Cloud Run / Cloud SQL (PostgreSQL) / Identity Platform / Cloud Scheduler・Run Jobs に移し、本人確認、管理権限、保存と運用を整えてから外部に公開する。メッセージ、多言語、フォロー関係、完全自動の定期収集などは現時点の完成機能ではない。現行機能と制約は [CAPABILITIES.md](CAPABILITIES.md) を参照。
